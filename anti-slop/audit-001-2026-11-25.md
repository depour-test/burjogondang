# Antislop Audit — BUR JO’SS (`audit-001-2026-11-25`)

Audit UI terhadap project `bur-joss` (`app/layout.tsx`, `app/globals.css`, `app/market.module.css`, `app/store.tsx`, `app/delivery-fields.tsx`, `app/merchant-qr.tsx`).

---

## Findings List

1. **[HIGH | R-02]** Em dash (`—`) digunakan di `<title>` (`app/layout.tsx`) dan placeholder nominal checkout `Subtotal` / `Total` (`app/store.tsx`).
2. **[HIGH | R-03]** Beberapa tombol aksi (`.add-button`, `.icon-button`, `.quantity button`, `.mobileNav a/button`) berukuran di bawah target sentuh minimum `44px`, dan deskripsi menu disembunyikan (`display: none`) pada layar `<=510px` (`app/globals.css`, `app/market.module.css`).
3. **[HIGH | R-39]** `cursor: pointer` di base CSS hanya dipasang pada `button` (belum mencakup `a[href]`, `select`, `summary`, `checkbox`, `radio`), ikon dekoratif belum memakai `aria-hidden="true"`, dan `<label className="search">` membungkus `<input>` sekaligus tombol clear (`app/globals.css`, `app/store.tsx`).
4. **[HIGH | R-40]** Elemen `<img>` hero (`.dish`), foto produk, dan QR pembayaran belum memiliki atribut `width` dan `height`, serta stylesheet Google Fonts di `<head>` memuat 3 font family secara render-blocking (`app/layout.tsx`, `app/store.tsx`, `app/merchant-qr.tsx`).
5. **[HIGH | R-27]** Tidak ada loading state saat mengambil data katalog awal dari API (`Store` langsung menampilkan `fallback` statis seolah data live sudah termuat) (`app/store.tsx`).
6. **[HIGH | R-25]** Potensi kontras rendah pada teks `.open` dan `.copy p` di atas gradien banner, focus outline `#ad7e14` di atas permukaan krem terang, serta tombol disabled dengan `opacity: .47` (`app/globals.css`, `app/market.module.css`).
7. **[MEDIUM | R-04]** Seluruh ikon UI menggunakan set default Lucide tanpa diferensiasi atau alasan kesesuaian konten warung (`app/store.tsx`).
8. **[MEDIUM | R-01 / R-12 / R-14]** Banner hero memakai gradien 3-warna generik dengan foto piring melayang berbayangan besar, serta 5 kartu kategori tampil seragam tanpa variasi hierarki (`app/market.module.css`, `app/store.tsx`).
9. **[LOW | R-29 / R-31 / R-20]** Inkonsistensi palet dan dead CSS: `market.module.css` memakai tema terakota/oranye (`#a53c0d`), sedangkan tombol `.button.dark`, `.quantity`, modal, toast, dan panel admin di `globals.css` masih memakai tema hijau (`#075754` / `#184c39`), disertai ~100 baris CSS lama yang tidak terpakai (`.hero`, `.warung-banner`, `.shop-strip`).
10. **[LOW | R-06 / R-15]** Menggunakan 3 keluarga font (`Fraunces`, `DM Sans`, `Manrope`) sekaligus tanpa satu suara tipografi yang fokus, serta headline/CTA hero (`"Makan enak, ala BUR JO’SS."` / `"Pilih menu"`) masih terasa generik (`app/layout.tsx`, `app/store.tsx`).

---

## Follow-up Report

**Design Read:** *Local warung ordering storefront (BUR JO’SS, Gondang Raya) for hungry students/locals, in a warm terracotta-and-cream editorial style, dial ENERGY 2 / RHYTHM 2 / MOTION 1.*

Seluruh 10 temuan telah diperbaiki pada `app/layout.tsx`, `app/globals.css`, `app/market.module.css`, `app/store.tsx`, dan `app/merchant-qr.tsx`:
- **R-02**: Menghapus em dash (`—`) dari `<title>` (`BUR JO’SS | Pesan Makan`) dan placeholder nominal checkout (`Menghitung…`).
- **R-03**: Menyesuaikan ukuran `.add-button`, `.icon-button`, `.quantity button`, dan `.mobileNav a/button` ke minimal `44px`, menampilkan deskripsi menu dengan 2-line clamp pada `<=510px`, serta menambahkan `flex-wrap: wrap` pada `.product-bottom` dan breakpoint 3 kolom pada `<=1120px` agar stepper kuantitas tidak keluar dari kartu.
- **R-39**: Menambahkan `cursor: pointer` untuk seluruh elemen interaktif di base CSS, `aria-hidden="true"` pada ikon dekoratif, dan mengganti `<label className="search">` menjadi `<div className="search" role="search">`.
- **R-40**: Menambahkan `width` dan `height` pada gambar hero, foto menu, dan gambar QRIS, serta menyederhanakan font menjadi 2 keluarga (`Fraunces` + `DM Sans`).
- **R-27**: Menambahkan state `catalogLoading` dengan banner status `Memuat harga dan status warung terbaru…` saat katalog awal dimuat.
- **R-25**: Mengganti gradien 3-warna hero dengan permukaan solid hangat `#f7ebe0`, meningkatkan kontras teks `.muted` (`#5c5048`), focus ring (`#a53c0d`), dan tombol disabled.
- **R-01 / R-12 / R-14**: Mengganti foto piring melayang berbayangan besar dengan frame editorial 4:3, serta mengubah strip kategori menjadi chip filter yang ringkas.
- **R-29 / R-31 / R-20**: Menyatukan palet terakota (`#a53c0d`), espresso (`#241c17`), dan krem (`#faf7f2`) di `globals.css` dan `market.module.css`, serta menghapus ~100 baris dead CSS tema hijau lama.
- **R-06 / R-15**: Memperbarui copy hero menjadi `"Nasi hangat & Indomie, langsung dari wajan."` dengan CTA `"Lihat daftar menu"`.
