# Antislop Audit #2 — BUR JO’SS (`audit-002-2026-11-25`)

Audit lanjutan berbasis inspeksi visual screenshot rendered (`978x794`) dan seluruh modul UI (`app/store.tsx`, `app/market.module.css`, `app/globals.css`, `app/delivery-fields.tsx`, `app/delivery-fields.module.css`, `app/admin/panel.tsx`, `app/admin/qris-settings.tsx`).

---

## Findings List

1. **[HIGH | R-03]** Logo `BUR JO’SS` di sidebar terpotong/mepet batas kanan pada viewport `~978px` karena lebar kolom sidebar (`clamp(185px, 16vw, 232px)`) terlalu sempit untuk ukuran `.brand-mark` + teks `22px` (`app/market.module.css`, `app/globals.css`).
2. **[HIGH | R-39]** Ikon dekoratif di `app/admin/panel.tsx`, `app/admin/qris-settings.tsx`, dan `app/delivery-fields.tsx` belum memakai `aria-hidden="true"`, beberapa `<button>` belum memiliki `type="button"`, dan pencarian admin masih membungkus `<input>` di dalam `<label className="search">`.
3. **[HIGH | R-26 / R-32]** Item navigasi `Beranda` di sidebar selalu tampil aktif permanen lewat `.side nav a:first-child` meski user sedang di bagian `#menu` atau membuka modal `Promo`/`Keranjang`, dan `Modal` belum mengembalikan fokus ke tombol pemicu saat ditutup (`app/market.module.css`, `app/store.tsx`).
4. **[HIGH | R-40]** Elemen `<video className="qris-camera">` pada pengaturan QRIS admin belum memiliki dimensi `width`/`height` atau `aspect-ratio` eksplisit untuk mencegah layout shift (`app/admin/qris-settings.tsx`, `app/globals.css`).
5. **[MEDIUM | R-04]** Seluruh ikon masih menggunakan set default Lucide, dan 48 dari 53 menu yang belum punya foto tampil sebagai kotak ikon generik besar (`fallback-photo`) yang mendominasi layar saat user scroll (`app/store.tsx`, `app/globals.css`).
6. **[MEDIUM | R-14 / R-05]** Chip kategori `Topping 4` jatuh sendirian ke baris kedua (*orphan wrap*) pada lebar ~978px, dan daftar menu masih 100% grid kartu identik tanpa variasi hierarki antara menu andalan berfoto dan menu reguler tanpa foto (`app/market.module.css`, `app/store.tsx`).
7. **[LOW | R-29 / R-31]** Sisa palet hijau teal lama (`#f0f8f5`, `#126657`, `#183d37`, `#9fc5bd`) masih tertinggal di `app/delivery-fields.module.css` (pilihan *Ambil sendiri / Antar* dan kotak *Tujuan pengantaran* di Checkout), bentrok dengan tema terakota-krem storefront.
8. **[LOW | R-06 / R-20]** Label kategori uppercase berulang di tiap kartu (`NASI`, `INDOMIE`) menambah noise visual, dan secara keseluruhan kartu + sidebar masih terasa terlalu "SaaS marketplace rapi" dibanding karakter papan menu warung makan (`app/store.tsx`, `app/globals.css`).

---

## Follow-up Report

Seluruh 8 temuan Audit #2 telah diperbaiki:
- **R-03**: Lebar sidebar diperbesar ke `clamp(216px, 18vw, 248px)` agar logo `BUR JO’SS` tidak terpotong di `978px`.
- **R-39**: Seluruh ikon dekoratif di `admin/panel.tsx`, `admin/qris-settings.tsx`, dan `delivery-fields.tsx` diberi `aria-hidden="true"`, tombol non-submit diberi `type="button"`, dan search admin memakai `<div className="search" role="search">`.
- **R-26 / R-32**: Sidebar kini memakai `data-active` dinamis sesuai bagian/modal aktif (`Beranda`, `Daftar menu`, `Promo`, `Keranjang`, `Pesanan saya`), dan `Modal` mengembalikan fokus ke tombol pemicu saat ditutup.
- **R-40**: `<video className="qris-camera">` diberi `width={480} height={360}` dan `aspect-ratio: 4 / 3`.
- **R-04 / R-14 / R-05 / R-06 / R-20**: Menu berfoto tampil di grid foto unggulan, sedangkan menu tanpa foto tampil di papan menu warung ringkas (`.menu-board`) tanpa kotak ikon generik besar; chip kategori dirapikan ke satu baris tanpa orphan wrap; label kategori kartu hanya muncul pada tampilan `Semua Menu`.
- **R-29 / R-31**: `delivery-fields.module.css` disatukan ke palet terakota-espresso-krem (`#faf3ec`, `#a53c0d`, `#fff0e4`).
